name: onboard
description: Import what you, this project's repositories and your company already have, from documents and rule files to git history, wikis and tickets, into your company's Shared Memory.
disable-model-invocation: true
---

Call the `onboard` tool of the `shared-memory` MCP server and follow the steps it returns, in order. The server holds the steps, so every coding agent follows the same ones.

If the tool says this repository isn't connected to a project, connect it first as the `shared-memory` skill describes, then call `onboard` again.
